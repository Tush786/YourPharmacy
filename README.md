# 💊 Pharmessy – Online Pharmacy Web App

An online pharmacy front-end where users can browse medicines, view product details, add items to the cart, and pay securely. Built by a team of 5 during a **5-day Construct Week** using **HTML, CSS, and JavaScript**.

## ✨ Features

- **Login / Sign Up** – user registration and authentication
- **Home Page** – navigation (Medicines, Doctor, Pharmacy, Other Services), search bar, promotional banners, product categories with filter
- **Product Page** – product details, description, key benefits, manufacturer info, price, discount, delivery estimate, quantity selector and *Add to Cart*
- **Cart Page** – view and manage selected items, price summary
- **Address & Payment Page** – delivery address entry and payment through Razorpay (UPI, Cards, Netbanking, Wallet)
- Responsive, clean UI

## 🚀 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/<your-username>/<repo-name>.git
   ```
2. **Open the project folder**
   ```bash
   cd <repo-name>
   ```
3. **Run it** – open `index.html` in your browser, or use the VS Code *Live Server* extension.
